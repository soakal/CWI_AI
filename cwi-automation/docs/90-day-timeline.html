Phase 1 — Foundation

Goal: Get tools set up, first chatbot working, outreach system ready.
Week 1
Stack Setup
  • Create Make (make.com) account — start on free tier
  • Create Freshchat account — free tier (up to 10 agents)
  • Set up OpenRouter account, confirm API key works
  • Create Apollo.io account — free tier to start
  • Set up a dedicated business email domain for outreach (hello@[yourbusiness].com)
  • Set up email domain authentication: SPF, DKIM, DMARC records
  • Create a simple one-page website or landing page (can use free Carrd.co)
🏁 Milestone: All accounts created, API keys tested, domain authenticated
Week 2
First Build
  • Build your first chatbot in Freshchat using your own business as the "client"
  • Connect it to Google Calendar via Make — test a full appointment booking flow end to end
  • Test edge cases: full calendar, off-script questions
  • Document exactly what you built — this becomes your standard "Starter" package template
  • Write your first client FAQ set (20–30 sample Q&A for a plumber — reusable template)
🏁 Milestone: Working chatbot + scheduling demo you can show on a screen share
Week 3
Outreach Prep
  • Scrape Southgate/Downriver area businesses from Google Maps (use Outscraper free tier)
  • Import list into Apollo — filter by industry: plumbers/HVAC and dentists
  • Personalize email templates from Outreach Email Sequences file per industry
  • Set up 3-email sequences in Apollo (one per industry: plumber, dentist, accountant)
  • Set up a simple calendar booking link (Calendly free tier) for discovery calls
  • Review and finalize your contract template, pricing calculator, and support playbook
🏁 Milestone: 150+ leads loaded in Apollo, sequences ready to launch, calendar link live

Phase 2 — Outreach & First Clients

Goal: Get your first paying client signed and live.
Week 4
Launch Outreach
  • Send first batch: 25 emails per industry (75 total) — start small to test messaging
  • Monitor reply rates daily — target 8–12% reply rate
  • Respond to every reply within 24 hours
  • Book discovery calls with qualified leads (use qualification framework)
🏁 Milestone: First discovery calls booked
Week 5
Discovery Calls
  • Run discovery calls — keep them to 20–30 minutes
  • Use the pricing calculator during each call to land on a monthly price
  • Send a follow-up email with one-page summary + price within 24 hours of each call
  • Continue outreach: send 25 more emails per industry
🏁 Milestone: First proposal sent
Week 6
Close First Client
  • Follow up on open proposals (3-day and 7-day follow-up if no response)
  • Handle objections — use ROI math: "a single recovered appointment pays for this"
  • When a client says yes: send contract via DocuSign/HelloSign, collect setup fee
  • Begin onboarding immediately once contract + setup fee received
  • Continue outreach (25 emails/industry)
🎉 Milestone: First client signed — setup fee collected
Week 7
First Client Go-Live
  • Run onboarding: get access to their systems, build their chatbot, test end-to-end
  • Go live — monitor closely for the first 72 hours
  • Document anything that breaks or surprises you — update templates accordingly
  • Continue outreach, focus calls on second client
🎉 Milestone: First client live and paying monthly retainer
Week 8
Stabilize + Pipeline
  • Check in with first client — how's it going? Any issues?
  • Collect a testimonial or early feedback quote (use it in future outreach)
  • Aim to have second client proposal out
  • Review which industry/email sequence got the best response rate — double down on that industry
🏁 Milestone: Second proposal sent, first client stable

Phase 3 — Scale to 3–5 Clients

Goal: Get to 3 paying clients — enough to cover platform costs and prove the model.
Week 9
Client #2 Close
  • Close second client, begin onboarding
  • Refine onboarding process based on what you learned from client #1
  • Increase outreach volume: 50 emails/industry/week (150 total/week)
🏁 Milestone: Second client signed
Week 10
Two Live Clients
  • Second client live
  • Aim for third proposal out
  • Begin building Phase 2 service (invoicing/payment follow-up) if client #1 or #2 is interested
🏁 Milestone: Two clients live, third in pipeline
Week 11
Three Clients
  • Close third client
  • At 3 clients: review your platform costs vs. revenue — confirm positive margin
  • Identify which industries are converting best — refocus outreach there
  • Consider upgrading Make plan if workflow volume is growing
🎉 Milestone: Three clients live
Week 12
Review & Plan Next 90 Days
  • Full review: What worked in outreach? What broke in builds? What took more time than expected?
  • Update pricing if needed (did complexity estimates hold up?)
  • Update contract if anything came up that wasn't covered
  • Set target for next 90 days: 5–8 clients, first Phase 2 service upsell
🏁 Milestone: 90-day retrospective complete, next phase planned

Risk Flags — Watch For These

Risk Signal Response
Low reply rate (<3%) After 100+ emails sent Rewrite subject line + first line; try different industry
Long sales cycle Proposals going cold after 7+ days Add urgency to follow-up; offer a free 15-min demo
Build taking too long First client taking >2 weeks to go live Simplify scope; do fewer features, more reliably
Support overload Spending >2 hrs/week on one client Escalate their support tier or revisit pricing
Churn Client cancels in first 90 days Interview them — understand what failed; fix before next client
