How to use in Gmail

  1. Edit fields on the left until the preview looks right.
  2. Click Copy HTML above.
  3. Open Gmail → Settings (gear icon) → See all settings.
  4. Scroll to Signature, create or edit a signature.
  5. Click in the signature text area, then press Ctrl+A to select all, then Ctrl+V to paste.
  6. Scroll down and click Save Changes.
